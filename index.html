About

Beam 1 · clockwise · injected at P2 Beam 2 · counter-clockwise · injected at P8

Beam readouts use simplified accelerator relations: dipole field from B = p / (0.2998 ρ) with ρ = 2804 m, luminosity from the round-beam formula with a crossing-angle factor, pile-up from an 80 mb inelastic cross-section, and intensity burn-off from the collision rate.

Bunch motion on the map is slowed by about 10⁵ so that trains and the 3 µs abort gap are visible. The machine clock runs at the chosen multiple of real time, so a 20-minute ramp takes 20 seconds at ×60. Durations follow a typical Run 3 cycle.

This is an educational illustration, not a validated accelerator model or live CERN data. Event categories, rates and tracks are synthetic demonstrations; candidate frequencies are not physical predictions. Ring circumferences are scaled, but the layout is schematic.

Pure HTML, CSS and JavaScript. No libraries. Optional Google Fonts load when online. Pause freezes the simulation; the machine clock follows active simulation time and slows if the browser cannot keep up.
